# Preprocessing scripts

Scripts to regrid various datasets to use them as forcings or ICs in MoNOS simulations.

## Corrected Normal Year

The Corrected Normal Year Forcing version 2.0 can be used as a forcing in MoNOS.
To do so, first download the raw data by running `downloads/download_CNYF_v2.0.sh`.
Then, run `preprocessing/regrid_CNYF.py` with the approriate options.
